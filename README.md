# Fuelerz — Next-Gen Digital Studio Website

Fuelerz is a high-energy creative studio website built for a digital design, branding, website development, and marketing business based in Goa, India.

The website is designed around the Fuelerz brand identity: bold black backgrounds, neon orange-pink-purple gradients, brush-stroke energy, animated UI elements, floating doodles, smooth interactions, and a customer-first layout that helps visitors understand services, view work, and contact Fuelerz easily.
